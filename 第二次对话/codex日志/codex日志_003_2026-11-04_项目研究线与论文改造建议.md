## 研究问题与已完成结果
- 背景问题：SpikeLLM 用 saliency 把激活通道拆成低显著与高显著子集，并为显著通道分配更多 spiking/量化预算。但在普通 affine min-max fake quant 中，量化 scale 仍可能由更宽的整体 token 激活范围决定；极端值会压缩普通通道的有效分辨率。项目 OSDSQ v2 的目标，是在 saliency 路由已确定后，让低显著支路的量程由该支路的激活分布决定，避免高显著/离群通道污染低显著支路的 scale。
- 本地代码的关键做法：`spike_linear.py` 中 `_quant_low` 用 saliency mask 屏蔽高显著通道（现 mean-shield 版本以低显著子集均值替代），将其输入低分支量化器做动态 min-max 校准后再将高分支位置置零；高显著分支调用 `act_quantizer_high(inputs)`，该分支仍按整条输入校准后乘高显著 mask。故论文应准确写成“低显著分支 range isolation / subset-conditioned scale”，不要夸成所有分支均独立估 scale，也不要写成单纯改一行 scale 而不解释分支算子。
- 已有证据（来自项目交接与第七轮结果记录）：7B W4A4 fake PPL，三种子配对 WT2 降幅约 24.04%±0.43%，C4 约 22.34%±0.14%；第七轮 seed2/seed3/seed4 的原始结果显示 Original WT2 10.5726/10.6303/10.5389，Ours 7.9792/8.0948/约 8.04。FP16 WT2 5.4722。真实多比特 PPL与 fake binary 接近但略差。A-off 只有 seed2（WT2 10.4181），不能跟 Full 三种子直接做强统计比较。
- 第七轮 mean vs zero 逐位等价，因此没有构成有效算法对照；当前应定位为“隔离量程”的证据，而不是“均值锚定更优”。命题“r² 预测收益”被 22 层分析否证，不可在论文继续主张。ACE/SOP 结果尚未用实测发放率和硬件端能耗闭合；将节省倍数写成实测能耗会过度宣称。

## 原论文 SpikeLLM 在相关问题上的处理
- 原论文用 GIF 将时间/幅值折中，并在 Optimal Brain Spiking 中用激活一阶 saliency / 权重二阶 Hessian 指标挑出显著通道。
- W4A4 实例通常将约 10% saliency 通道给 T=2 多步编码（表 2 也报告 5% 与 4-step 选项），其余通道用一步；阈值 `Vth=max(x)/T'` 为 per-token 形式。它优化“哪些通道值得分配更多离散预算”，不是显式优化每个 saliency 子集的量化参数估计域。
- 当前 OSDSQ 的差异点应是：沿用原 saliency mask/路径，将低显著路径 scale 的统计域从全体激活改为被选中的低显著子集，并以 W4A4 7B 端到端 PPL 验证。注意这和改变时间步数/位宽是两个概念，需把 addbit/T 对照与 range-isolation 对照拆清楚。

## 相关工作启发与边界
1. ICLR 2026 phase coding：以激活分布驱动多粒度可学习 phase bases，减少统一编码粒度的分布失配，并做 LLM 转换。启发：研究分布失配不应只停留在 min-max scale，可验证“显著度分组是否也需要分组码本/分组 phase basis”；价值在跨表征机制复现。风险：与 distribution-aware coding 的主张相邻，只有“子集统计域改变可带来一致改善”的系统对照和公平预算才有新增量；不得仅凭论文图表宣称该仓库码本是全局/分组，需源码核查。
2. LAS AAAI 2026：用 OAT 双子神经元处理 outlier/normal 及 HG 近似非线性，并覆盖注意力/FFN/LN/Softmax。启发：outlier 双路径/双阈值已有先例；“拆出离群值”或“双分支”本身不新。可研究阈值/scale估计域跟随 saliency 子群而非只按 outlier 门限，或与 OAT 作公平比较。避免把分组本身宣称为创新。
3. SpikingLM ICML 2026：Distribution-aware Scaling 改善死神经元/梯度并可融合；Spike2Max 处理 attention competition。启发：若本方法定位量化 range distribution shift，要区别于训练动态范围缩放（其主要目标是可训练性/activation-friendly range），并避免重复声称“distribution-aware”。更强可扩展方向是跨归一化/残差层的统计域传递，但目前证据不足，应作为后续路线而非本文贡献。
4. STAtten：在视觉 SNN 中用 block-wise spatial-temporal attention 建模时间依赖。和当前 LLM 激活范围问题距离较远，最多启发将 temporal budget 与统计分布联合优化，不宜当成直接相关基线。
5. APT-LLM：展示真实 arbitrary precision tensor-core、数据恢复与 kernel mapping 能决定实际速度。启发本项目 ACE 需从抽象位宽能耗估计推进到实际 latency/energy / kernel 证据；当前没有实现级加速，不宜以“实际节能/速度提升”作为论文主结论。
6. 学院文件：硕士成果要求含 CCF-A 计 3 分；学术/专业硕士均要求成果与学位论文相关、学生为第一完成人或导师一作学生二作、第一署名单位东北大学，且投稿需导师同意。科研投稿目标之外，还需核对自身培养类型与积分规则。

## 论文改造建议（优先级）
- P0 先把研究主张写成可证伪问题：在相同 saliency mask、W/A bits、calibration tokens、LET/LWC、seed 和测试集下，低显著支路采用全局估计域 vs 低显著子集估计域，是否稳定降低端到端误差？把 shielding 操作、统计域、部署成本分别定义清楚。
- P0 拆开实验因素：A. range domain（global/isolated，含等价 mask、zero/mean 代理诊断）；B. code resolution/time steps (`addbit`/T sweep)；C. selection strategy（saliency vs random）。否则第八轮 addbit 同时改变 high branch bits 与 T，不能反证/证明 range isolation。
- P0 补强基线与公平性：Full/A-off 至少匹配三种子；统一 68M 的冲突数字；同预算下报告 Orig/Full 随 T 的 Pareto 曲线；明确 fake/real mode、校准数据、PPL评估版本与模型版本。
- P1 证明机制：报告按层/通道的 full-range 与 low-subset range、有效量化步长/饱和率、低支路 MSE 变化，展示改善集中在哪些层；不要再用被证伪的 r² 定量预测。
- P1 扩到至少第二个模型尺寸或独立框架。候选之一是 phase-coding 的 grouped-vs-global phase basis/scale（需源码与可运行性先核实）。若仅 SpikeLLM 支持，明确单框架适用范围，不声称通用共性。
- P1 预算/部署：同时报告逻辑运算上界、实际发放率、估算假设与真实 GPU/神经形态硬件不可比限制；如果不做 kernel/能耗实测，标题/摘要不要承诺加速。
- P2 Related Work 应直接承认 saliency split、outlier-specific neurons、distribution-aware coding 与 distribution scaling 已出现；本文新点收敛到“显著度路由后、分支内量化统计域错配的识别与可零推理开销修复”，并由强消融/跨方法复制来支撑其普适性。

## 总判断
- 目前工作是有可观端到端信号的机制修复型项目，但 novelty 仍窄，且核心证据被单组件依赖、addbit/T confound、ACE物理成本口径与跨框架缺失削弱。现有状态不应称“已达到 CCF-A 顶会完整投稿强度”。是否能冲取决于尽快获得 addbit/T 点位并将 range-domain 与 code-resolution 两条证据正交化，再做一个可复现的外部框架验证。
- 建议本文候选主线：Saliency-guided spiking quantization should allocate both coding budget and calibration domain to the same subset. 这是待验证假设，不是已证明结论。
