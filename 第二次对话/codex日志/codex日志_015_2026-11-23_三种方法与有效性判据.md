# 三种方法怎么比，哪些数字能支持哪些结论

2026-11-23。用户原话：「讲一下我们的方法和你找到的两篇论文的区别，再告诉我有哪些数据可以对比，只要哪些数据好就能证明我们的方法有效」。随后用户说「继续」。

本轮已阅读 Work Buddy 011、Antigravity 018，复核第十轮三种子消融、第十二轮原始配置与零样本分项、Codex 011–014。实验室最新回传仍为第十三轮。核对 SpikeQuant 作者预印本表 1、2、4、公开程序，以及 QuantaSpike 表 1、2、7 和附录 A.2。

## 三种方法

我们的 7B 主配置在部署前选高精度通道。在每个 token 上，用普通通道自身的数值确定该线性分支的量化范围。离线搜索在同一块的七个线性投影间分配有限的高精度通道，按高分支名义乘加记账，用块输出与高精度参考的均方误差比较配额。部署后固定通道名单，普通组的当次量程仍随输入更新。主结果来自模拟量化。

SpikeQuant 用离线校准和推理时的异常判定，按每次输入的激活值选普通/异常类别，报告普通 4 位、显著 5 位，用脉冲出现时间表示数值。作者实现对 token 内分组，先排除已判异常的值，再算普通组的最小值和最大值。普通组独立统计量程的具体运算已有公开代码。[SpikeQuant 方法与表格](https://arxiv.org/html/2510.19498v1) · [官方实现](https://github.com/wangchenyu929/SpikeQuant/blob/main/workflow/snn_utils.py#L144-L155)

QuantaSpike 按当前激活的偏离程度和幅度选出异常值，用余下数值估计组增益。普通值用最多三个残差脉冲步，选中异常值可以先发一次起始脉冲，再走同一残差编码。7B 组大小为 64，最多四步。两篇论文均已处理异常值干扰普通值表示的问题。项目的具体可检验差异是保留静态通道选择并搜索块内跨投影配额。[QuantaSpike 方法、表 1–2、附录 A](https://arxiv.org/html/2609.34259v1)

## 能支持的主张

- 普通通道隔离能改善本管线的语言预测。7B 三种子成对，保持其余 Stage 1 改动，从关到开 WT2 10.2818→8.0370，C4 13.0319→10.7018。
- 保持高分支名义乘加预算，用整块误差搜索比均匀配额更好。三种子 WT2 8.0370→7.5932，C4 10.7018→10.1320，分别再降 5.52% / 5.32%。seed2 搜索也优于固定 down/o 策略（7.5296/10.1216 对 7.8057/10.4114）。固定策略多种子、强管线和同配置下游增益仍待核实。
- 声称比 SpikeQuant 或 QuantaSpike 好，应先以同一模型权重、文本和工具测 FP16 及各方法；对齐可比成本、披露各自分组和异常比例。在相近成本下两语料 PPL 稳定更低、五项平均不退化或改善，支持质量优势。若质量持平但实测推理耗时或每 token 能耗更低，支持效率优势。需报告波动、整模型与一次性校准成本，区分理论窗口、实际事件及硬件测量。
- 最便宜的下一项是拿现有 7B seed2 Stage 1 检查点与完整方法做同口径五项和六项。冲外部比较先选公开代码明确的 SpikeQuant，同一 7B 测试；其 group size 128 细分组也会提升精度，诊断对照可在同样分组下比较策略。无需用总下降比例代替直接比较或指定任意百分比为门槛。
