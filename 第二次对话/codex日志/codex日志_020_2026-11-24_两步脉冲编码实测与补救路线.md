## 1. 有基础的研究问题

保留原流程的正结果。7B 三种子 Stage 1 → 再做配额分配的平均 PPL 为 WikiText-2 8.0370 → 7.5932、C4 10.7018 → 10.1320。强流程预演的第二步收益小，1.1B 较宽预算下两项指标方向相反。新增假设聚焦于显式执行：当高支路最多发两次、每次负载 0 至 15 时，同一组量化值能否少发非零包？省下的执行预算能否转给对预测最有帮助的通道？这让已有的精度和配额实验成为基线。公开查新不支持申报首次分组、首次反码或首次按成本分配。

## 2. 单元定义与本地探针

- 使用本机原始 JackFram/llama-68m（2 块，14 个线性投影，CPU FP32）与 TinyLlama 1.1B（22 块，154 个投影，GPU FP16 前向）。采集浮点模型输入激活，用 FP32 按原流程计算显著度和每 token 非对称 5 位码，不含训练后的平滑、裁剪、量化权重和上游误差。每个投影固定约 10% 高通道，分母为这些通道各个激活出现次数。
- WikiText-2 缓存中编号 0–7 的窗口各取前 256 token，识别高通道并拟合固定方向的对照。WikiText-2 另取 64–71，每段前 256 token。C4 在既有测试缓存的前 8 个 2048 窗口各读前 256 token，沿用 WikiText 的名单和固定方向。每语料 2048 个评估 token。两个模型按各自缓存读取，样本量不足以主张全分布泛化。本轮只读事件，不用 C4 的 PPL 来选参数。
- 现有两步等权累加回放只能传 0–30，5 位代理的 31 会成 30。主测试先令 q=min(5位整数, 30)，保留旧显式路径已经能够解码的数。用现有整数零点 z 判断，z>15 时传 30−q，其他情况传 q。方向在每个 token 的一个投影内共享。逆变换得到 q−z。线上实现应在累加后处理整组的方向和零点，逐值解码再走稠密乘法只可用作数值参照。核心假设是非零多位包可以被计数、零包可跳过。[量化规则](../../SpikeLLM/spike_driven_quant/quantizer.py) · [两步实现](../../SpikeLLM/spike_driven_quant/spike_linear.py)
- 一次非零包的计数为 1[q>0]+1[q>15]，幅值 1–15 的包在此记一次。另按每个投影输出宽度加权。一个多位包和一个二值脉冲的代价可能不同。零点修正、方向处理、访存、低支路、注意力和硬件焦耳均未计入这张表。

四组在上述已可达整数上的解码差异计数均为 0。1.1B 零点规则相对按校准集为每个通道选固定方向，未加权包数再少 15.50% / 16.56%。逐 token 穷举从固定刻度的两端出发，零点规则仅多发 0.30% / 0.27%。诊断也比较了允许共享原点移动的参照与带符号幅值参照。后者若按每个正、负的 1–15 幅值均记一个包，在 1.1B 可比零点规则再少 41.76% / 42.46%，两份样本各有 8 个值需要第三步。该方法需要可表示符号的负载或运算，严格两步时还需处理例外；应与真实支持它的实现公平比较。没有硬件或成本模型支持时，不能把无符号窗口的节包数写成系统节能。

另测一个允许参考起点随组移动的版本，联系精度和事件数。若同一 token 高支路的原始整数最大值减最小值不超过 30，全组都能精确表示，连 31 也能传到。比如该组为 1–31，统一减 1，发送范围恰为 0–30；恢复时再加 1。若原始跨度为 31，沿用旧路径把 31 截至 30。两种情况下，在可传的目标上分别从最小值正数、从最大值倒数，选总包数较小的一端。每步包数随待发整数单调递增，在“每组共用一个整数起点和方向、保持单位刻度”的类别内，这两个起点已经覆盖最优解。显式检查每个包的可达范围以及整数解码结果。该版本需要组内极值与方向决策，计数优势尚未扣除这些操作。

## 3. 旧证据的价值和边界

第二轮 7B、seed2、开启增强损失时，Stage 1 由直接量化到显式多步模拟，WT2/C4 为 7.9792/10.6792 → 8.1570/10.8975。Original 为 10.5726/13.7738 → 10.8108/14.1855。整模型切换同时触及注意力与加法顺序。顶码丢失可由代码推出，但其对整模型差距的占比待测。[旧报告](../../第一次对话/实验室日志/第二轮日志/第二轮日志/README_索引.md)

复核 R11 s2/s3 和 R12 s4 各 32 个块的配额日志。每个投影从 low 列数换算实际报告的 high 目标列数。down/o 各有 29/32 层的配额整数在三个种子完全相同，所有七处都相同只有 4/32 层。以另外两个种子的同层同投影占比均值预测留出种子，等权平均绝对误差 1.22 个百分点，统一 10% 规则约 4.63 个百分点。down 打到 20% 附近的情况为 84/96；最后一层的 down 三次均约 6%。上界与步长会制造相同结果，重复配额不保证相同通道或模型精度。

三个日志从每层开始到配额摘要的时间加总为 7125/7066/7049 秒，占首层开始至末层 iter19 的 25.85%/25.76%/25.69%。这段还含显著度等准备，是从头搜索可节约时间的宽松上界。备选实验是固定 s2 整数配额，换新校准文本时重排通道，在预先保留的新种子上比较端到端校准耗时和 PPL，两个旧种子的回顾性结果只能做探索。[R11 s2](../实验室日志/第十一轮日志/log/r11_7b_aq_s2/log_rank0_1794806931.txt) · [R11 s3](../实验室日志/第十一轮日志/log/r11_7b_aq_s3/log_rank0_1794835227.txt) · [R12 s4](../实验室日志/第十二轮日志/02_原始日志/r12_7b_aq_s4_log_rank0_1795059876.txt)

## 4. 与前人以及下一张卡时的关系

- SpikeQuant 做逐值混合精度和二值脉冲重编码，QuantaSpike 做三元残差、异常值起始脉冲和事件成本。NSLLM 已分层选择时间模式，Int2Spike 已支持二值、三元和逐位补码。已有 SNN 工作明示 M−V 互补表示，DAQ 已关注真实发放决策对齐。论文的新命题只能建立在特定执行预算、等价性、代价和可在强基线上重现的收益之上。[SpikeQuant](https://arxiv.org/abs/2510.19498) · [QuantaSpike](https://arxiv.org/html/2609.34259v1) · [NSLLM](https://academic.oup.com/nsr/article/13/4/nwaf551/8365570) · [Int2Spike](https://github.com/BICLab/Int2Spike) · [互补脉冲表示](https://www.mdpi.com/2079-9268/15/3/50) · [DAQ](https://arxiv.org/abs/2611.22611)
- 单卡优先让已有 R13b 恢复流程完成，再在已确认可恢复的大模型检查点只评测，冻结权重、低支路、掩码、注意力路径和文本。比较正向、校准后固定方向、零点选方向、强替代编码。记录显式支路输出、最终 logits 及两语料 PPL；核算非零包及扇出、幅值/二值代价、符号、零点修正、传输与读写。真正的延迟或功耗主张另需相应实现测量。端点差异应单独开关，分离注意力和浮点归约的影响。
- 省下的事件可以重投到最敏感的投影。用校准文本比较候选交换的整块误差降低除以额外事件成本，在单独文本和多个预算点看精度—事件曲线。旧 AQ 的列数×输出宽度、相同编码的固定比例都是必要对照，再用同一模型与文本协议比较 SpikeQuant，标明二值、三元、多位的成本假设。若强对照在全部合理预算下更优，或收益被编码和纠偏吞掉，降低该路线优先级。时间不足时先保证大模型冻结检查点和外部基线，不盲目扩展种子。
