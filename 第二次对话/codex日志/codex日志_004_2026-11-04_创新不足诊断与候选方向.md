# Codex 协作日志 004 · 2026-11-04 · 对创新不足的判断与增强方向

## 用户原话
> 我始终觉得目前的创新点不足，你觉得呢，有什么可以改进的额外的创新点吗

## 前置阅读
- 复读 Work Buddy 最新日志 002 与协作规程 v2；第二轮 Antigravity 日志、实验室回传仍为空。
- 参考本轮已读材料与日志 003：SpikeLLM ICLR 2025、phase coding ICLR 2026、LAS AAAI 2026、SpikingLM ICML 2026，及本地 SpikeLLM 核心实现。

## 判断
- 同意用户直觉：只讲“mean shield / range isolation”，目前容易被评价为实现修补；现有主结果好，但单一技术改动贡献窄，机制与成本证据不够。
- 不应简单堆叠更多小技巧。需要把问题从“换一种scale统计”提升为“脉冲预算如何依据子群分布与任务误差被有效分配”，并与已有 saliency-based fixed allocation 明确区分。

## 建议的主创新候选
提出 saliency-conditioned rate-distortion allocation（显著度/分布/脉冲预算联合分配）作为研究假设：
1. 按激活分布与任务敏感度将通道划分子群，每个子群有自己的量化域/scale（当前range isolation作为基础组件）；
2. 对每个通道/子群，在可选时间步/码本精度下测量校准集上的层输出失真增量与成本增量；
3. 在给定真实估计成本/发放率或严格明确的ACE代理预算下，给“单位成本能最多降低多少任务敏感失真”的组分配额外时间步；
4. 以等预算 Pareto 曲线验证优于固定10%/T=2 saliency 分配与全局scale基线。

差异不能只叫“更好的saliency”：原 SpikeLLM 已有 saliency-based 通道识别和固定档位步数配置。真正待验证的新点是“依据分支统计域与边际失真/成本联合选择分组、scale和时间步”，并需要源码/文献查新确认相关 rate-distortion/混合精度工作是否已覆盖。

## 两个备选方向
A. 在 phase coding 上做 saliency-conditioned multi-granularity basis/codebook：不同显著度/分布子群用不同 phase 基，但共享总事件/码本容量预算。强项是跨框架验证；风险是与 ICLR 2026 distribution-aware multi-granularity coding 重叠高，必须以“saliency条件化+等成本/损失增益”为具体差异，并先完成源码核查。
B. 校准到推理分布漂移的鲁棒范围估计：不仅用静态 min-max，而是对尾部漂移做风险受限的clip/scale选择，报告PPL尾部风险/分布外稳定性。风险是容易变成常见动态量化/异常值处理，需要脉冲特有成本与真实应用收益。

## 关键实验前置
- 第八轮 addbit 同时影响高分支位宽和 steps，不能替代单因素 budget experiment；先把 range-domain 与 temporal-budget 正交。
- 成本模型要先核实 fake/real路径、真实 firing rate 与物理算量，未实测时只能叫代理成本。
- 增益必须同时在模型规模/种子上复现；补 A-off 多种子、等预算基线、saliency-vs-random、固定比特/固定事件两种口径。

## 结论
- 当前点子单独支撑CCF-A说服力不足；较有潜力的增强不是再添一个量化补丁，而是把“显著度选择 + 子群统计域 + 时间步/码本容量”联合成可求解的预算分配问题，以同成本 Pareto 支配和跨框架验证支撑贡献。
- 这是新研究方案，不是已证明的新颖性结论；正式立项前还需系统查新并验证可执行性。
