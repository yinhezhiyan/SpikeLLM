# SpikeQuant、QuantaSpike 对 ICML 投稿的影响

2026-11-23。用户原话：「spikellm毕竟是2025年的老论文了，我们跟他做对比能发出去吗，还是说我们必须跟那个发表在**The Web Conference 2026**   上的论文做对比。你说的QuantaSpike没发表在真正的期刊或会议上面是吧，**The Web Conference 2026**  是什么级别的会议，我们发ICML时，审稿人会看到那个跟我们差不多的文章吗，或者说，你直接告诉我，你找到的这两篇文章对我发论文有没有影响」

已读 Work Buddy 011、Antigravity 018 与最近的 Codex 讲义，当前实验室回传截至第十三轮。核查会议规则、论文发表记录与相关研究，并对照第十至十二轮的配对结果。

## 会议与日期

- The ACM Web Conference，简称 WWW，属于 CCF 推荐 A 类会议，列入交叉／综合／新兴方向。ACM 主会议论文集收录 SpikeQuant，正式出版日期 2026-04-12，页码 5334–5345，作者已公开代码。[CCF 第七版目录公告](https://www.ccf.org.cn/Academic_Evaluation/By_category/2026-03-31/870181.shtml) · [CCF 的 WWW 会议条目](https://www.ccf.org.cn/Academic_Evaluation/Cross_Compre_Emerging/zgjsjxhtjgjxshy/al/2017-04-25/592216.shtml) · [SpikeQuant 正式发表记录](https://doi.org/10.1145/3774904.3792337)
- QuantaSpike 的 arXiv v1 发布于 2026-09-28。截至本日核查，尚未找到期刊或会议正式录用记录。其是否曾投过其他会，目前没有可靠结论。[作者预印本记录](https://arxiv.org/abs/2609.34259)
- ICML 2027 全文截止为 2027-01-22（AoE）。官方评审说明把全文截止前不足两个月才公开的工作视作同时期研究，可以不讨论，未经过同行评审的文献则结合子领域惯例判断。QuantaSpike 的公开时间早于两个月窗口。主会指南要求评估原创性和重要性时考虑此前研究，重点看遗漏会不会改变贡献结论；没有指定作者必须重跑哪一篇论文或每项指标取得第一。[ICML 2027 审稿说明](https://icml.cc/Conferences/2027/ReviewerInstructions) · [ICML 2027 征稿通知](https://icml.cc/Conferences/2027/CallForPapers)

## 本项目的投稿决定

1. 保留 SpikeLLM，用相同的实现和配置回答原方法损失多少、两个改动各补回多少。仅用这组比较支撑对当前整个方向的优势，证据不足。
2. SpikeQuant 是优先实验对手。它点明 SpikeLLM 的固定显著通道及尺度问题，且作者代码已经按被判普通的值单独定尺。现有两篇相关工作都限制第一阶段的首创表述。7B 报告的 WikiText-2/C4，两篇分别约为 5.79/7.33 和 5.78/7.23，项目为 7.59/10.13。各家试卷与计算方式有差别，仅能作公开参照。[SpikeQuant 论文](https://arxiv.org/html/2510.19498v1) · [SpikeQuant 普通分支代码](https://github.com/wangchenyu929/SpikeQuant/blob/main/workflow/snn_utils.py#L144-L155) · [QuantaSpike 全文](https://arxiv.org/html/2609.34259v1)
3. 单卡优先统一 7B 权重、测试文本和计分，复测 SpikeQuant 对完整方法；同时保留预算相同的固定比例／搜索对照。QuantaSpike 在正文辨析方法和报告值、标明预印本及不同测法；是否复现取决于能否公平执行以及文章最终声称什么。同行能看到两篇公开工作，具体分到的评审是否已读无法判断。
4. 当前可认领的证据是，在实验室 SpikeLLM 流程中，普通通道量程隔离和七个计算单元之间的离线配额分配可以带来增益，第二步在高精度乘加预算内使两语料困惑度再降 5.52% / 5.32%。尚待估计的是强基线上的增益、相近成本下的质量或同等质量下的实际效率。两篇文献提高了证明门槛，尚未证实它们已做同一项跨投影配额实验。
