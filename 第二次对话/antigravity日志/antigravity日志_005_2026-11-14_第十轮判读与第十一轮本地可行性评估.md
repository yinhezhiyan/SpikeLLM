逐项原因如下：

| 第十一轮任务 | 模型规模 | 本地能否运行？ | 原因与硬约束说明 |
| :--- | :--- | :--- | :--- |

     - `A-off` 三种子均值：WT2 = **`10.2818 ± 0.1353`**（`10.4181 / 10.1475 / 10.2797`），C4 = **`13.0319 ± 0.1005`**（`12.9691 / 12.9787 / 13.1478`）。
     - 对比 `Ours Full`（`8.0370 ± 0.0578`）与 `Original`（`10.5806 ± 0.0462`）：在完整方法内开启线性量程隔离（`A-off -> Full`），WT2 降低 **`21.83%`**（配对均值差 `-2.2447 ± 0.1931`，`95% CI = [1.7651, 2.7244]`，$p = 0.00246$），C4 降低 **`17.88%`**。
2. **完全赞同 Codex 007 的统计与因果表述纠偏**：
   - Codex 007 独立复算的配对统计（`A-off - Full = 2.2447449 ± 0.1930964, p = 0.00246`；`Orig - A-off = 0.2988218, p = 0.0909`）与原表完全吻合。
   - **采纳 Codex 007 的两项严谨性修正**：
     1. 不在论文中声称“已证明 88% 为交互效应”，因为 `Orig`、`A-off`（即 `Orig + B/C/D`）、`Full`（即 `Orig + A + B/C/D`）三格测出的是 **A 在 B/C/D 存在条件下的条件主效应（Conditional Effect，降幅 21.83%）** 以及 **B/C/D 在无 A 时的单独效应（2.82%，未达显著）**；若要严格拆解主效应与交互项，需有 `Orig + A only` 第四格。论文中直接诚实陈述“B/C/D 在未隔离量程时仅带来 2.82% 的微弱改善，而在此基础上引入线性支路量程隔离（A）进一步带来 21.83% 的显著下降”，既严谨又同样有力。
     2. 采纳 Codex 007 对百分比方向与分母的规范：`Full` 相对 `A-off` 降低 `21.83%`（`(10.2818 - 8.0370) / 10.2818`），反过来关掉 A（`Full -> A-off`）会导致 PPL 恶化（上升）**`27.93%`**（`(10.2818 - 8.0370) / 8.0370`）。
