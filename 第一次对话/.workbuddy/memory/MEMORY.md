## 今天新增的两条致命事实

1. **`addbit` 旋钮从未被测**：82 次实验全是 addbit=1（T=2），0 次 addbit=2/3。而自家 ACE 公式下 addbit=3 只比 addbit=1 贵 5%（16.4→17.2）。审稿人必问"为什么不直接调大 addbit"。**必须先测 Original@{1,2,3}。**
2. **命题二破产**：22 层同口径 MSE 缩减均值 1.89×，与 r 的 Pearson −0.166 / Spearman +0.243 / log-log 斜率 −0.08；收益随深度上升而非随 r。r² 只是松散上界，无预测力。初稿 §5.4 的 3.12× 是"orig 无 LET ÷ ours 含 LET"的混淆口径，同口径为 1.76×。
