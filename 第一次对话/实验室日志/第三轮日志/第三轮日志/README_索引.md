## 二、结论：D 是正向的，而且比等权更好

| 第二目标的形态 | WikiText-2 (fake) | C4 (fake) |
|---|---|---|
| 无第二目标（`--aug_loss` 关，A+B+C） | 8.4223 | 11.2824 |
| **等权 1.0、无余弦**（本次消融，原版形态） | **8.2403** | **11.1289** |
| **加权 0.25 + 余弦**（正式配置，A+B+C+D） | **7.9792** | **10.6792** |

三档**单调下降、没有反转**。逐步增益：

| 步骤 | fake wt2 | fake c4 | real wt2 | real c4 |
|---|---|---|---|---|
| 无 → 等权 1.0 | −2.16% | −1.36% | −2.96% | −2.26% |
| 等权 1.0 → 加权 0.25 + 余弦 | **−3.17%** | **−4.04%** | **−1.98%** | **−4.27%** |
| 无 → 完整（总收益） | −5.26% | −5.35% | −4.88% | −6.43% |

**D 的增量贡献 2.0%–4.3%，方向明确为正，不是可删项。**

### 与开发机预期的出入

GLM 预测"在 7B 上 D 可能不如等权第二目标"——**实测不支持**（D 7.9792 优于等权 8.2403）。但他们另一句"D 的边际收益小于等权 aug 在 Original 上的收益（−7.1%）"**成立**（D 边际只有 −2.0% ~ −4.3%）。

顺带验证了他们反对的 7.82 外推：按 `8.42 × (1−7.1%)` 会得到 7.82，实测等权是 **8.24**，外推比实际乐观了 0.42 个 PPL —— 那条批评完全站得住。

## 七、论文建议（来自本轮报告 §五）

1. **保留 D。** 删掉会掉 0.26–0.44 PPL。
2. 消融表按"无 / 等权 1.0 / 加权+余弦"三档写，比"D vs 无 D"信息量大。
3. 诚实表述："D 在 68M 上是最大贡献组件（+4.4 PPL），在 7B 上增益被更强基座吸收、边际收窄到 2%–4%，但仍稳定为正。"
4. D 的边际收益只有 2%–4%，排期紧张时此项可只跑 seed=2 单次。
